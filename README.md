# Deepfake Video Detector

ResNet50 + XGBoost deepfake detection for videos, with a Flask API + React frontend.

---

## Requirements

| Dependency | Version | Purpose |
|------------|---------|---------|
| Python | 3.10+ | Backend / ML pipeline |
| Node.js | 20+ | Frontend dev server |
| CUDA GPU | Optional (falls back to CPU) | Faster inference |

---

## Setup

### 1. Python Environment

```bash
# Create and activate virtual environment
python3 -m venv venv
source venv/bin/activate

# Install Python dependencies
pip install torch torchvision opencv-python xgboost scikit-learn flask joblib numpy pillow matplotlib seaborn tqdm
```

### 2. Model Files

Download the pre-trained XGBoost model and face detector:

```bash
# The trained model is at:
# models/xgboost_deepfake.pkl  (generated by extract_all.py)

# Download OpenCV DNN face detector files:
wget -O models/deploy.prototxt https://raw.githubusercontent.com/opencv/opencv/master/samples/dnn/face_detector/deploy.prototxt
wget -O models/res10_300x300_ssd_iter_140000.caffemodel https://github.com/opencv/opencv_3rdparty/raw/dnn_samples_face_detector_20170830/res10_300x300_ssd_iter_140000.caffemodel
```

### 3. Node.js Frontend

```bash
cd frontend
npm install
```

---

## Run

### Terminal 1 — Backend (Flask API)

```bash
source venv/bin/activate
python app/app.py
```

Serves on `http://127.0.0.1:5000`

### Terminal 2 — Frontend (Vite Dev Server)

```bash
cd frontend
npm run dev
```

Opens at `http://127.0.0.1:5173`

> The Vite dev server proxies `/api/*` requests to Flask automatically.

---

## API

`POST /api/predict` — upload a video file (`multipart/form-data`)

```bash
curl -X POST http://127.0.0.1:5000/api/predict \
  -F "video=@/path/to/video.mp4"
```

Returns JSON:

```json
{
  "label": "FAKE",
  "confidence": 0.8735,
  "duration": 30.3,
  "fps": 24.0,
  "faces_detected": 5,
  "frames_checked": 25,
  "total_frames": 727,
  "frame_results": [...]
}
```

---

## Training (Optional)

To retrain the model from scratch:

```bash
source venv/bin/activate
python extract_all.py
```

Requires FaceForensics++ dataset in `FF++/fake/` and `FF++/real/`.
